Why does Raft require a majority quorum of (N/2)+1 servers to elect a leader?

In Raft, requiring majority = (N/2)+1 guarantees the Pigeonhole Principle: any two majorities must overlap by at least one server. That overlapping server cannot vote twice in the same term, preventing dual leaders (split-brain).

quorum.go Copy 
func hasQuorum(votes, totalNodes int) bool {
    return votes > (totalNodes / 2)
}
